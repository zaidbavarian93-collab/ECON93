# أقسام كلية الإدارة والاقتصاد – جامعة السراج الأهلية

صفحة تعريفية تفاعلية لطلبة الكلية: الأقسام الأربعة، وقاعاتها الدراسية، وفرص العمل، واختبار قصير لكل قسم.

الصفحة منشورة على GitHub Pages من هذا الفرع (`gh-pages`):
https://zaidbavarian93-collab.github.io/ECON93/

## روابط الأقسام
| القسم | الرابط | رمز QR |
|---|---|---|
| إدارة الأعمال | https://zaidbavarian93-collab.github.io/ECON93/#ba | `qr/ba.png` |
| المحاسبة | https://zaidbavarian93-collab.github.io/ECON93/#acc | `qr/acc.png` |
| العلوم المالية والمصرفية | https://zaidbavarian93-collab.github.io/ECON93/#sfb | `qr/sfb.png` |
| اقتصاديات النفط والغاز | https://zaidbavarian93-collab.github.io/ECON93/#og | `qr/og.png` |

## روابط القاعات
كل قاعة تُفتح برمزها بعد علامة `#`، مثل `#ba01` و`#acc02` و`#sfb03` و`#og01`،
ورموز QR الخاصة بها في مجلد `qr/` بالاسم نفسه (مثل `qr/ba01.png`).

هذا الفرع منفصل عن كود برنامج Notch في الفرع `main` ولا يؤثر فيه.
